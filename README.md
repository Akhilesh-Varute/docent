# Docent

Ask your documents. Get answers with citations.

Docent is a document Q&A assistant built on AWS Bedrock. I am building it
in public as I learn, adding one capability each week.

## Roadmap
- [ ] Week 1: Call Bedrock with tool-calling
- [ ] Week 2: LangGraph agent
- [ ] Week 3: RAG with pgvector
- [ ] Week 4: FastAPI endpoint
- [ ] Week 5: Evals and tracing
- [ ] Week 6: Deploy on ECS or Lambda with CI/CD
